# 部署与备案 —— 决策记录

> 这份文件记录**为什么这么选**,以及**卡在哪一步**。下次会话读这个就能接上。

## 结论(2026-09-22 定)

**买阿里云深圳(内地)轻量应用服务器,并走 ICP 备案。**

## 为什么(三条都是查证过的硬约束,不是偏好)

### 1. 小程序必须备案 ⇒ 只能内地服务器

微信官方文档《网络 / 使用说明》原文:

> 每个微信小程序需要事先设置通讯域名,小程序**只可以跟指定的域名进行网络通信**。
> *   域名**必须经过 ICP 备案**;

**没有中间地带** —— 小程序的网络请求只能发往已备案域名,连 GitHub Pages 都不行。
而 **ICP 备案只对中国内地服务器发放**,香港/海外服务器拿不到备案号。

⇒ 只要小程序是目标形态(它是),就必须有内地服务器。

### 2. 但备案要等,期间不能解析

阿里云文档《未备案域名解析至不同地区是否可以访问?》原文:

> 域名解析至 **中国内地** 服务器的网站等服务,**必须完成备案才可对外提供访问服务**。
> 如域名解析指向服务器为阿里云中国内地服务器,如果您未在阿里云提交过备案,
> 直接将域名解析至阿里云中国内地服务器上,**将被阿里云监测系统识别并阻断网站的访问服务**。

⇒ 备案期间只能用 **IP** 开发调试,`z.cevtuogrnd.com` 解析上去会被阻断。
⇒ 备案耗时约 **1–3 周**。

### 3. 英国朋友不受备案影响 —— 走另一条线

备案只约束**内地服务器**。现有的 GitHub Pages(`data/` 已经在那)不在约束内,
**H5 / Android 继续用它,英国朋友直接可访问**。

所以两条线并行,互不阻塞:

| 用途 | 载体 | 备案 | 谁能用 |
|---|---|---|---|
| 小程序 | 阿里云深圳 | 需要 | 国内用户 |
| H5 / Android / 分享 | GitHub Pages | 不需要 | 英国朋友 + 所有人 |
| 数据源 `data/` | GitHub Pages | 不需要 | 两边都读 |

## 域名规划

```
apps.cevtuogrnd.com   ← 分发页(独立,保持不变)
z.cevtuogrnd.com      ← 本项目
```

两个都在 `services/sync-trigger` 的 CORS 白名单里 —— 因为项目页将来要从分发页链接过来。

⚠️ 将来加新项目:一台服务器跑多个项目是标准做法,nginx 按域名分流 +
每个项目独立目录 + 独立 systemd 服务。**不需要每个项目买一台。**

## 卡在哪 ⏳

**需要用户本人完成、无法代劳的两件事:**

1. **阿里云扫码登录** —— 自动化 Chrome 的 profile 副本里登录态已过期。
   真实 Chrome 是登录的,但 Copilot 那套副本用的是 rsync 出来的快照,Cookie 过期了。
   登录页:`https://account.aliyun.com/login/login.htm`(二维码用阿里云APP/支付宝/淘宝扫)
2. **下单支付 + 备案提交** —— 短信验证码、实名认证(身份证/人脸)、支付密码。
   这三样只有账号本人能提供。**任何声称能绕过它们的做法都不要接受。**

## 服务器选型

截图里那台:`2 vCPU / 2 GiB / 40 GB SSD / 200 Mbps / 无固定流量 / 1 IPv4`,¥45/月(年付 8.5 折 = ¥459/年)。

**够用** —— 同步服务只占 ~50MB 内存,nginx ~20MB,静态数据 13MB。

⚠️ **长期瓶颈是磁盘,不是 CPU/内存。** 若打算放很多项目:
- Docker 镜像一个就 1–2 GB
- 40 GB 扣掉系统后余量有限
- ⇒ 优先选 **60 GB 以上**的规格,或接受将来挂数据盘

⚠️ **地域选定后不可更改**(换地域 = 重新买 + 重新备案)。

## 备案流程(阿里云)

⚠️ **备案需要「备案服务码」,而服务码只能由符合条件的阿里云云产品提供**
⇒ **必须先买服务器,才能提交备案**。顺序不能反。

1. 买深圳轻量服务器
2. 控制台申请**备案服务码**
3. 提交备案:主体信息(个人/企业)+ 域名 + 服务码
4. 阿里云初审(1–2 天)→ 管局审核(约 1–3 周)
5. 期间:用 IP 部署调试,不解析域名
6. 通过后:解析 `z.cevtuogrnd.com` → 申请 SSL 证书 → 开 HTTPS

⚠️ 小程序还要求 **HTTPS 且证书校验通过**,所以证书这步不能省。
