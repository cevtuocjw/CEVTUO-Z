## 四、这一轮抓到的四个 bug（都是「看起来正常」那种）

### 1. ⚠️⚠️ 把倾斜动画整个弄死了，而且是静默的

画框降到 `z-index: -1` 之后，`.section` / `.stack` 这些**铺满视口的容器**画在它上面，
而**指针事件只发给最上面那个元素** ⇒ 画框一个事件都收不到。

**症状是零**：位置对、尺寸对、颜色对，截图上看不出任何异常，**只是不会动了** ——
而「会不会动」正是读者要的全部东西（「要那种高级感的动画」）。
实测：鼠标移到画框正中心，`--tx` 一次都没被写过，`gal--press` 从来没挂上过。

⇒ 修法**不是**把 z-index 调回去（那就退回「压住正文」），而是
**把「谁画在上面」和「谁收到事件」解耦**：监听挂 `window`、按几何命中；
`.gal` 改 `pointer-events: none`；每帧先读完全部矩形再写样式。

### 2. ⚠️ Taro 把上一页留在 DOM 里

`.taro_page` 被置为 `display: none`，于是 `document.querySelector('.gal')`
拿到的是**隐藏那页上的那个**：rect 全 0、`getAnimations()` 空、`transform` 是 `none`
⇒ 断言报「玻璃没有在流动」，**看起来像产品坏了**，而产品是好的。

触发路径很绕：窄屏上画框压在正文上面，而它是 `pointer-events: none`，
**测试的点击穿过去落到卡片上、触发了导航**。
⇒ 脚本里一切查询走 `window.__root()`（当前可见的那个 `.taro_page`）。

### 3. 主页三枚都放背景那张图

背景是 `g02`，画框也放 `g02` ⇒ `float` 那枚和壁纸**糊成一整块**。
DOM 上一切正常（枚数对、图加载了、方向对），**是看截图看出来的**。

### 4. ⚠️ 重写验证器时，把原文件抬头警告过的坑又犯了一遍

内页的 `photos` 夹具忘了给 ⇒ 读到上一页残留的那枚画框 ——

## 七、操作上的坑（每次都踩）

- ⚠️⚠️ **部署必须 `nohup`**，否则 Shell 一重置就死。
  ```bash
  rm -f apps/dashboard/dist/data
  (GIT_CONFIG_COUNT=1 GIT_CONFIG_KEY_0=http.version GIT_CONFIG_VALUE_0=HTTP/1.1 \
     nohup bash scripts/deploy-pages.sh >/tmp/deploy.log 2>&1 &)
  ```
- ⚠️ **部署要跑好几分钟**（逐个 `curl` 拉上一版的 chunk，这一轮是 **132 个**）。
  **看起来像卡死，其实在跑** —— 判据是 `pgrep -fl deploy-pages`。别急着杀掉重跑。
- ⚠️ **推 `main` 前先 `git fetch`**（远端有定时 Actions 在写数据，这一轮撞到过一次）。
- ⚠️ **必须落地的步骤一有结果就做**，别留到收尾 —— 工具调用有**每轮 30 次**上限，
  撞上就整轮中止，**未执行的调用一个字都没跑**（这一轮撞了三次）。
- ⚠️ zsh 不做默认分词（`set -- $vp` 不会按空格拆）；`--include=*.tsx` 要**加引号**；
  URL 里的 `?` 要**加引号**；全角字符紧跟 `$VAR` 会被吞 ⇒ 写 `${VAR}`。
- ⚠️ **`/tmp` 里的探针不随仓库走**（`probe.mjs` / `probe2.mjs` / `tilt.mjs` /
  `week-sheet.mjs` / `week-geom.mjs` / `glass.mjs`）。下次开窗口它们可能已经没了 ——
  值得留下的要**搬进 `scripts/`**。
